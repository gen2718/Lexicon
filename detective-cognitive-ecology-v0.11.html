Axis Calibration Guide

使い方と分析の前提

この画面はAlpha Version 6.0のSecond-Pass Analytical Interfaceです。新たな採点Frameworkではありません。元の8 Elements / 4 Layersを再定義せず、検証したい認知構造を別の2軸に配置します。

研究上の問い

Hidden State ▶︎ Evidence Interface ▶︎ Cognitive Operation ▶︎ Temporal Integration ▶︎ Reality Reconstruction

HolmesianからDetectiveへ

Holmes × Watson × Decodable World × Social Code × Urban Information Architectureを出発点とし、認知主体を個人に固定せず、人物対・制度・歴史・文化・環境へ広げます。

操作

  1. 作品NodeをクリックするとInspectorが更新されます。ダブルクリックまたはFocusで内部Networkを開きます。
  2. Overlayは必要なものだけ追加します。Formalismの輪のパターンは可視性を示し、品質やNodeの重要度を示しません。
  3. Compareで任意の2作品と内部Networkを並べます。共通Evidenceのカテゴリ化は編集上の対応付けであり、原語の完全一致とは分けて表示します。
  4. CalibrationをONにしてNodeをドラッグします。選択中のNodeにフォーカスして矢印キーで1、Shift＋矢印で5ずつ動かすこともできます。Inspectorの数値入力でも調整できます。
  5. ノートを書いたら「座標・Noteを保存」を押します。HTMLは自動では上書きされません。「共有・データ保存」から変更を含むHTMLを保存して渡してください。

Temporalの意味

単なるテンポではなく、統合の配置・持続・順序・遅延・再構成を指します。Shot〜Seriesは時間的単位、Institution・Environmentなどは統合の成立する文脈です。ひとつの数値尺度にはまとめません。

Working Concept / 研究仮説

Detective Cognitive Ecologyは現段階ではWorking Conceptです。Sophisticationの方向をひとつに定めず、元のFrameworkにE9などの採点Elementを追加しません。

Version 0.11 · Calibration Edition

小数精度を避けた整数表示、両軸のOperational Anchors、Microの4種類のEdge Semanticsだけを改訂しました。初期6座標、Evidence Interface、Classは0.1から維持しています。

旧Version 0.1の小数座標は内部値と位置を保持し、表示だけ整数に丸めます。ドラッグや明示的な座標編集では整数にSnapします。

Design Notes · 維持した設計

実装：MacroとMicroを分け、Evidence・Temporal・Formalismを段階的に重ねます。座標とNote、選択Concept、表示状態を独立した検討版として保存・共有できます。

今回含めないもの：新規採点、Classからの位置計算、Episode別の未提供データの補完、同時共同編集。これらは現状の根拠やローカル単体という目的を越えるためです。

Version 0.2候補：複数人のCalibration差分、場面単位の出典、仮説の変更履歴、Episodeごとの認知系の推移。

拡張点：Work・Concept・Internal Nodeの固定IDとVersion 2用metadata。Function / Layer Reach / Path / ContributionとSecond-Pass情報を、既存の座標とは独立に追加できます。

出典と限界

6作品の初期座標・分析経路・Evidence・Concept・Class注記はユーザー提供仕様に基づきます。内部Networkの型・配置・補助Edge、Integration Locusのタグ、共通Evidenceカテゴリは可視化のための編集仮説です。

Alpha 6.0の全文、作品別の全分析、場面単位の裏付けは本データセットに含まれていません。記載は分析仮説として共同検討するためのもので、独立した作品検証や新しい採点を意味しません。

ClassはInspector内の参照情報だけに表示します。座標やNodeサイズへ自動反映しません。Saga／Martinは異なる認知系として対等に表現します。

研究用データのため作品の解釈・結末に触れます。共有すると内蔵の分析と保存したNoteも共有されます。

変更を含めて、ほかの人へ渡す
